\section{Benchmark}
\label{sec:benchmark}

To validate the network independently of the labels used in training, we construct a closure test with a known, injected charge-flip function. A flexible discrete-kernel model (a \texttt{FiniteKernel}) is first fit to the truth-matched electrons, giving a smooth reference flip probability \(\epsilon_{\mathrm{ref}}(x)\) as a function of true kinematics. Treating \(\epsilon_{\mathrm{ref}}(x)\) as ground truth, synthetic SC/OC samples are generated by stochastically flipping the reconstructed charge of each electron in the di-electron dataset with probability \(\epsilon_{\mathrm{ref}}(x)\), yielding a benchmark for which the true flip function is known exactly.

The di-electron classifier of \cref{sec:method} is trained on this synthetic benchmark, and its learned \(\phi(x)\) is compared directly against the injected \(\kappa_{\mathrm{ref}}(x)=\log\!\big(\epsilon_{\mathrm{ref}}(x)/(1-\epsilon_{\mathrm{ref}}(x))\big)\). The same classifier, unmodified, is then applied to the ATLAS Open Data sample of \cref{sec:Opendata}, learning \(p(\mathrm{SC}\mid x_1,x_2)\) directly from true and reconstructed kinematics.

The classifier closes well on the synthetic benchmark, recovering the injected flip function. Performance is slightly degraded on real data, which we attribute to a resolution effect (\(p_T\) smearing between true and reconstructed kinematics) that is currently under investigation.
