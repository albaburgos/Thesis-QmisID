\section{ATLAS CERN Open Data}
\label{sec:Opendata}

As a proof-of-principle beyond simulation truth, the continuous framework is also applied to real collision data from the 2024 ATLAS Open Data release (\texttt{2024r-pp}). We use \(Z\rightarrow ee\) events from the \texttt{Sh\_2211\_Zee\_maxHTpTV2} sample (dataset ID 700320) in \texttt{DAOD\_PHYSLITE} format, streamed directly from the ATLAS Open Data endpoints with \texttt{uproot}. For each file, reconstructed-electron kinematics (\(p_T\), \(\eta\), \(\phi\), charge) and the existing electron-chain charge-ID decision (\texttt{DFCommonElectronsECIDS}/\texttt{ECIDSResult}) are read from the \texttt{AnalysisElectrons} container.

\subsection{Truth Matching}

Isolating charge misidentification in open data requires knowing, for each reconstructed electron, whether its assigned charge matches its true generator-level charge. Every reconstructed electron carries an \texttt{ElementLink} (\texttt{TruthLink}) to the corresponding truth particle, stored as a pair \((\texttt{m\_persIndex}, \texttt{m\_persKey})\): the index of the linked particle within its target container, and a hashed key identifying which container is targeted.

Two cases must be excluded before an index can be used. First, an unset link stores \texttt{persIndex} as the sentinel \(2^{32}-1\), rather than a real index. Second, because only the \texttt{TruthElectrons} container is loaded, a link whose \texttt{persIndex} exceeds that container's length in a given event does not indicate a bad match — it means the link legitimately points elsewhere, most commonly into \texttt{TruthPhotons} for electrons produced by photon conversion. With only \texttt{TruthElectrons} available, \texttt{persKey} alone cannot distinguish this case from a genuine match, so both classes of index are removed prior to lookup. The surviving indices are used to retrieve the matched particle's PDG ID and dressed \((p_T,\eta)\) from \texttt{TruthElectrons}, from which the truth charge follows directly (\(\mathrm{pdgId}=11\rightarrow q^{\mathrm{truth}}=-1\), \(\mathrm{pdgId}=-11\rightarrow q^{\mathrm{truth}}=+1\)). An electron is considered truth matched only if its link is valid, \(\texttt{persKey}\neq 0\), and the matched particle is a genuine electron or positron.

The truth-level QmisID label is then obtained by comparing reconstructed and truth charge for each electron,
\[
\ell^{\mathrm{truth}} = \mathbb{1}\!\left[q^{\mathrm{reco}} \neq q^{\mathrm{truth}}\right],
\]
independent of any detector-level identification algorithm. Events are additionally required to contain exactly two reconstructed electrons, each with \(p_T > 20\)~GeV, and both truth matched; the pair is then ordered by descending \(p_T\) and the dielectron invariant mass \(m_{\ell\ell}\) is formed from the leading and subleading four-vectors.
